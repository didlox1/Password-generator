# Cortex-M0+ Password Generator
University project for DesignLab classes.
This project implements a password generator using a Cortex-M0+ microcontroller and the KL05 module. It generates passwords based on configurable length and character types, such as uppercase letters, lowercase letters, numbers, and special characters.
The project demonstrates embedded C programming, microcontroller peripherals, user input handling, and basic password-generation techniques.

## Objectives

- Generate random or pseudo-random passwords
- Support configurable password length
- Include multiple character types
- Display or transmit the generated password
- Demonstrate Cortex-M0+ and KL05 module programming

## Technologies

- Cortex-M0+ microcontroller
- KL05 microcontroller
- ANSI C
- GPIO and peripheral interfaces
